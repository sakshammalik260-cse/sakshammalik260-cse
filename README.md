## 🔥 Featured Projects

### 📡 Smart Scan Strategy for Electronic Warfare

An AI/ML-based adaptive scanning system designed to improve signal interception in environments where reliable prior intelligence is unavailable.

**Highlights**
- Worked with large-scale HDF5 signal datasets
- Built adaptive and ML-based scanning strategies
- Compared Sequential, Logistic Regression, Random Forest, and adaptive scheduling approaches
- Used metrics such as detection rate, coverage, intercept delay, F1 score, ROC-AUC, and PR-AUC
- Developed an experimental pipeline with leakage-safe train/validation/test evaluation

**Tech:** Python, Pandas, NumPy, Scikit-learn, HDF5, Machine Learning

---

### 🏗️ ReBuild AI

A mobile-first AI/computer-vision concept for sustainable building renovation and demolition.

The system scans rooms or buildings and identifies reusable, recyclable, or disposable materials before renovation or demolition.

**Planned capabilities**
- Detect doors, windows, furniture, fixtures, tiles, glass, metals, cables, etc.
- Estimate quantity and condition
- Classify materials for reuse, recycling, or disposal
- Generate material recovery plans
- Create QR-based material passports
- Support circular construction and waste reduction

**Tech:** Python, FastAPI, YOLO, OpenCV, React / Flutter, PostgreSQL / Firebase
